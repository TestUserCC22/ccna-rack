# CCNA Rack

An offline study app for the Cisco CCNA 200-301 v2.0 exam: topic notes, practice questions, timed mock exams, spaced-repetition flashcards, IOS command drills and a subnetting trainer.

Open it at https://testusercc22.github.io/ccna-rack/ and add it to your home screen to install it.

- Works offline once installed (service worker).
- No server, no accounts, no API keys. Progress is stored only on the device, with backup and restore to a file under Settings.
- The questions are original practice material, not real exam questions.
